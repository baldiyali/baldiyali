## 🔧 Featured project

### [AI Tech Support Assistant](https://github.com/baldiyali/Ai-tech-support-assistant)
An AI-powered troubleshooting assistant for small companies without an IT department.

- **Guided diagnosis:** users describe a problem in plain English ("my laptop turns on but the screen stays black"), and the app asks targeted follow-up questions.
- **RAG with citations:** answers are grounded in uploaded manuals and approved support articles, with sources shown.
- **Automatic support tickets:** unresolved issues become structured tickets with symptoms, steps tried, device details, and a recommended escalation.

`Python` · `FastAPI` · `scikit-learn` · `SQLite` · `JavaScript` · `pytest` · `Playwright`
